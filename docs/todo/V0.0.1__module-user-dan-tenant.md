## User
User adalah pengguna yang akan menggunakan sistem Seneca HR ini. Setiap user memiliki roles. Rolesnya adalah `super -> owner -> admin -> employee`. Urutan yang paling kiri adalah roles dengan tingkat tertinggi.
1. `super`. User yang memiliki akses ke seluruh sistem. User ini hanya ada satu bernama `sysadmin`.
2. `owner`. User yang memiliki roles ini bisa meilhat dan management semua data tenant yang dia miliki.
3. `admin`. User yang memiliki roles ini bisa management pegawai yang dibatasi oleh permission.
4. `employee`. User yang memiliki roles ini bisa management data dirinya sendiri.

Seneca HR mendukung absensi dengan wajah, sehingga setiap user menyimpan informasi wajah kedalam bentuk vector.

User bisa berada di lebih dari satu tenant.

### Super
User super adalah user yang memiliki akses ke seluruh sistem. User ini hanya ada satu dan bernama `sysadmin`. Tidak boleh ada `sysadmin` lebih
dari satu.

### Owner
Setiap user bisa memiliki banyak tenant / perusahaan. User yang memiliki tenant disebut `owner`. Owner memiliki hak akses untuk melihat dan management data tenant yang ia miliki. Owner memiliki rules khusus yaitu `owner`. Setiap tabel root (Tabel yang tidak memiliki foreign key) harus memiliki id tenant `tenant_id`.
Fitur dari tenant :
1. Owner dapat membuat tenant baru dan management tenant tersebut.
2. Owner memiliki permission paling tinggi pada tenant tersebut.
3. Owner dapat menambahkan user / pegawai ke tenant tersebut.

## Admin
Admin adalah user yang memangement pegawai pada tenant yang dihandle. Hanya owner yang bisa memberikan user akses admin. Sistem ini bisa mengatur permission pada admin sehingga roles admin ini bisa lebih dari satu, contoh : admin pegawai, audit, mainter lokasi dll.
Fitur dari admin :
1. Admin dapat management pegawai tergantung permission yang diberikan.
2. Admin hanya bisa diassign oleh owner.

## Employee
Employee adalah user pegawai pada suatu tenant. User ini hanya bisa melihat informasi dirinya sendiri.
